# 🌍 Climate-Trail (Prototype)

**Climate-Trail** is a 2D narrative survival and simulation prototype built in **Godot Engine**. 

Set in a future heavily impacted by climate breakdown, the project places the player in the shoes of a survivor navigating resource scarcity, environmental hazards, and strategic survival decisions.

---

## 🎮 Project Highlights & Mechanics
- **Engine:** Godot Engine (`project.godot`)
- **Core Theme:** Climate crisis impact, environmental survival, and resource trade-offs.
- **Architecture:** Initial game scaffolding, scene setup, and baseline asset pipeline configured for modular feature expansion.

---

## 🛠️ Tech Stack
- **Engine / Framework:** Godot Engine (2D)
- **Scripting:** GDScript
- **Version Control:** Git & GitHub
